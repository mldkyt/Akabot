Verification modes

None

Members press the verification button and immediately receive the verification role. This is simple, but does not protect against automated button clicks.

Math problem

Members must solve a simple math problem before they can verify.

Silly verification

Members have to bark, meow or make a fox noise to pass the check. It is silly and here for no reason.

Introduction based

Members write an introduction in the configured introduction channel. An admin then approves it before the member receives the verification role.
