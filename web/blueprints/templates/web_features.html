Feature List

Automod Actions

Create additional Automod actions for your Discord Automod rules.

Chat Revive

Revives inactive channels if there's no seen activity for a set period of time.

Chat Streaks

Counts how many consecutive days you've sent a message in a Discord server.

Chat Summary

Counts messages and sends a summary at the end of each day.

Giveaways

Create and manage giveaways directly within your Discord server.

Leveling

Implement and manage a leveling system with XP, rewards, and multipliers.

Logging

Log Discord events and send them to a designated logging channel.

Message Time Capsule

Schedule messages, reminders, and collection messages in Discord servers and DMs.

Moderation

Kick, ban, timeout, and manage warnings for users in your server.

Reaction Roles

Assign or remove roles by reacting to messages. Supports normal, add-only, remove-only, and single-choice modes.

Roles on Join

Give members roles immediately when they join the server.

Statistic Channels

Channels that display various server statistics in real time.

Temporary Voice Channels

Let members create temporary voice channels on demand.

Verification

Prevent bots from accessing your server with user verification.

Welcome and Goodbye

Welcome new members and say goodbye to those who leave.
