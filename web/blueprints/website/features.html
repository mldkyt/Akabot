Check out Akabot's feature list:

Automod Actions

Create additional Automod actions for your Discord Automod rules.

Chat Revive

The Chat Revive commands revives commands if there's no seen activity for a set period of time.

Chat Streaks

The Chat Streaks module counts how many days you've sent a message consecutively in a Discord server.

Chat Summary

The chat summary module counts messages and then sends a message at the end of the day.

Giveaways

The Giveaways module allows server administrators to create and manage giveaways directly within their Discord server.

Leveling

The Leveling module allows server administrators to implement and manage a leveling system within their Discord server.

Logging

This module adds logging for a Discord server. It sends events into a logging channel.

Message Time Capsule

This module allows users to schedule messages, reminders, and collection messages in Discord servers and DMs.

Moderation

This module provides commands to perform moderation actions such as kicking, banning, timing out, and removing timeouts for users in a Discord server.

Reaction Roles

This module allows users to assign or remove roles by reacting to messages containing specific buttons. It provides commands to create different types of reaction role setups, such as normal, add-only, remove-only, and single-choice reaction roles.

Roles on Join

Give members roles immediately on join.

Statistic Channels

Channels that display various server statistics.

Temporary Voice Channels

Create as many voice channels in your Discord server without needing to ask admins to create them for you.

Verification

This module adds user verification in Discord servers. It prevents bots from accessing your Discord server.

Welcome and Goodbye messages

Welcome new members, and say goodbye to the ones who leave.
