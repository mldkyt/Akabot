# Nekona

Nekona is a featureful open-source bot and a full rewrite of Akabot!

Features:

- [Counting](https://git.the-wired.club/lain/nekona/wiki/Counting.md): Counting channels add a bit of fun into your
  server with channels purely for counting.
- [Leveling](https://git.the-wired.club/lain/nekona/wiki/Leveling.md): Adds levels, level-up rewards and more fun into
  your server.
- [Moderation Commands](https://git.the-wired.club/lain/nekona/wiki/Moderation%20Commands.md): The moderation commands,
  along with moderator roles, allow you to add an extra step for attackers to deal with when using bots to destroy your
  Discord server. Add your moderator role to moderator roles and remove the usual Discord permissions.
- [Chat Streaks](https://git.the-wired.club/lain/nekona/wiki/Chat%20Streaks.md): Chat Streaks allow you to see how
  chronically online are your members. It counts consecutive days of chatting. A chat streak is lost when the member
  skips a day.
- [Welcome & Goodbye Messages](https://git.the-wired.club/lain/nekona/wiki/Welcome%20&%20Goodbye%20Messages.md): You can
  use Nekona to welcome new members and say goodbye to those who leave. There are two grace periods available, one for
  before the welcome message is sent, and one for when the welcome message gets deleted (when a member leaves too
  quickly). Both can be disabled
- [Logging](https://git.the-wired.club/lain/nekona/wiki/Logging.md): This module logs events into the logs channel of
  your choosing.
- [Automod Actions](https://git.the-wired.club/lain/nekona/wiki/Automod%20Actions.md): Automod Actions allow you to
  perform extra actions when an AutoMod rule is triggered.
- [Chat Summary](https://git.the-wired.club/lain/nekona/wiki/Chat%20Summary.md): Chat Summary shows a summary of who
  sent how many messages at the end of the day.
- [Server Settings](https://git.the-wired.club/lain/nekona/wiki/Server%20Settings.md): Server settings help you adjust
  the Nekona settings for your server. There are 2 types of settings: normal settings and list settings. Available
  settings for each module of Nekona can be read under the respective page. Use the sidebar.
- [User Settings](https://git.the-wired.club/lain/nekona/wiki/User%20Settings.md): User settings help you adjust the
  Nekona settings for yourself. There are 2 types of settings: normal settings and list settings. Available settings for
  each module of Nekona can be read under the respective page. Use the sidebar.
- [Roles On Join](https://git.the-wired.club/lain/nekona/wiki/Roles%20On%20Join.md): Add roles to members who join the
  server
- [Chat Revive](https://git.the-wired.club/lain/nekona/wiki/Chat%20Revive.md): Dead channels? With the help of Chat
  Revive, you can revive them after a set amount of minutes.
- [Temporary VC](https://git.the-wired.club/lain/nekona/wiki/Temporary%20VC.md): Temporary voice channels.
- [Statistic Channels](https://git.the-wired.club/lain/nekona/wiki/Statistic%20Channels.md): You can set up channels
  that periodically update with the statistics of your server on the top of your server channel list. Create a voice
  channel and put it on top of the list, and ensure the bot has channel edit permissions.
- [Verification](https://git.the-wired.club/lain/nekona/wiki/Verification.md): You can set up verification for your
  server using the verification module. Members have to solve a simple math problem to verify.
