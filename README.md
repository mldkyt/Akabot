# Akabot

Akabot is a featureful open-source bot and a full rewrite!

Features:

- **Counting**: Counting channels add a bit of fun into your
  server with channels purely for counting.
- **Leveling**: Adds levels, level-up rewards and more fun into
  your server.
- **Moderation Commands**: The moderation commands,
  along with moderator roles, allow you to add an extra step for attackers to deal with when using bots to destroy your
  Discord server. Add your moderator role to moderator roles and remove the usual Discord permissions.
- **Chat Streaks**: Chat Streaks allow you to see how
  chronically online are your members. It counts consecutive days of chatting. A chat streak is lost when the member
  skips a day.
- **Welcome & Goodbye Messages**: You can
  use Akabot to welcome new members and say goodbye to those who leave. There are two grace periods available, one for
  before the welcome message is sent, and one for when the welcome message gets deleted (when a member leaves too
  quickly). Both can be disabled
- **Logging**: This module logs events into the logs channel of
  your choosing.
- **Automod Actions**: Automod Actions allow you to
  perform extra actions when an AutoMod rule is triggered.
- **Chat Summary**: Chat Summary shows a summary of who
  sent how many messages at the end of the day.
- **Server Settings**: Server settings help you adjust
  the Akabot settings for your server. There are 2 types of settings: normal settings and list settings. Available
  settings for each module of Akabot can be read under the respective page. Use the sidebar.
- **User Settings**: User settings help you adjust the
  Akabot settings for yourself. There are 2 types of settings: normal settings and list settings. Available settings for
  each module of Akabot can be read under the respective page. Use the sidebar.
- **Roles On Join**: Add roles to members who join the
  server
- **Chat Revive**: Dead channels? With the help of Chat
  Revive, you can revive them after a set amount of minutes.
- **Temporary VC**: Temporary voice channels.
- **Statistic Channels**: You can set up channels
  that periodically update with the statistics of your server on the top of your server channel list. Create a voice
  channel and put it on top of the list, and ensure the bot has channel edit permissions.
- **Verification**: You can set up verification for your
  server using the verification module. Members have to solve a simple math problem to verify.
- **Premium**: Every module has a free-tier limit. Redeem a premium code (timed or unlimited) to lift the limits and
  unlock more of every feature. Usage bars in the dashboard show where you stand.
- **Timezones**: Set your server's timezone so daily features like chat streaks and chat summaries follow your local
  day.
- **Reaction Roles**: Let members self-assign roles by reacting to or clicking buttons on a message.
- **Anti Raid**: Detect and automatically act on raids, with toggles for message floods, duplicate messages, mention
  spam, invite spam, excessive caps, emoji and sticker spam, join bursts and scam links.
- **Suggestions**: Turn a channel into a suggestion box with up/down voting and threads.
- **Periodic Messages**: Send a message in a channel on a repeating schedule.
- **Sticky Messages**: Keep a message pinned to the bottom of a channel.
- **Markov**: A markov chain bot that generates messages in the channels you enable (requires message intent).
- **Tags**: The bot replies with a message whenever a chat message contains a keyword (requires message intent).
- **Economy**: A NekoCoins economy with work, balance, transfer, rob, pay and gamble commands.
- **Mail**: Receive important messages from the bot directly in Discord.
- **Message Counting**: Track message counts and hand out rewards for hitting targets.
- **VC Notifications**: Get notified when members join voice channels.
- **Voting**: Vote for the bot and earn rewards.
- **Giveaways**: Host giveaways in your server. Members join by
  clicking the button on the message and winners are drawn when it ends.
- **Fun commands**: Whoa... fun :3 A pile of fun and
  roleplay slash commands.
- **Meowing Back :3**: A silly module (disabled by
  default) that makes the bot meow, bark, waf, awawa, owo or :3 back at users.
